# Pardavimai ir skolos

Paprasta programėlė maisto pardavimams ir skoloms skaičiuoti. Viskas viename `index.html` faile, be serverio.

**Duomenys saugomi tik jūsų telefone** (naršyklės saugykloje). Šioje saugykloje yra tik programėlės kodas.

## iPhone

1. Safari atidarykite https://autonetas1.github.io/maisto-apskaita/
2. Spauskite „Bendrinti“ → „Į pradžios ekraną“.
3. Toliau atidarykite tik per ženkliuką — jis veikia ir be interneto. Safari kortelėje ir ženkliuke duomenys atskiri.
4. Reguliariai darykite atsarginę kopiją: „Duomenys“ → „Atsisiųsti kopiją“ → „Įrašyti į Failus“.

## Patikra

Naršyklės konsolėje: `runTests()`.
